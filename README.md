# Veiled Concord — Rosterizer Stage 2

This package is the **v1.0 Playtest Stage 2** Rosterizer build for the Veiled Concord homebrew Warhammer 40,000 11th-edition faction.

## Included
- Stage 1 datasheets, points, weapons, keywords, Leader relationships and faction rules.
- 12 selectable detachments using the 11e Detachment Point system.
- 48 Enhancements with final playtest points.
- 72 Stratagems in WHEN / TARGET / EFFECT / RESTRICTIONS format.
- God-Engine Upgrade Enhancements made selectable on the two non-Epic TITANIC datasheets.
- Explicit Recall clarification: **ANCHOR only controls who can channel; a unit that loses ANCHOR remains eligible to be Recalled again later.**

## Next test
Import `Veiled_Concord.rulebook` into Rosterizer. Build a small roster first, preferably using **Colossus Warhost + Conclave of the Veil** so the multi-detachment DP selector is exercised. Export the roster as `.regiztry` and upload that file to Yellowscribe.

At this stage the main thing we are testing is Rosterizer/Yellowscribe compatibility. Some extremely specific Enhancement restrictions that depend on what unit a Character is *leading* are intentionally described in the rules text rather than fully machine-validated yet.
